ALGORITHME II

La probabilité avant le test, ou pourquoi le même signe ne vaut pas le même prix

Le principe

La probabilité après le test dépend d'un nombre qui ne figure sur aucun compte rendu : la probabilité avant le test. Elle n'est pas une opinion. Elle se construit sur trois éléments que le Traité documente maladie par maladie.

Le terrain. L'âge, le sexe, la maladie systémique connue, l'ascendance quand elle est documentée.

Le contexte. La prévalence de l'atteinte dans la population d'où vient le malade, et non dans la population générale.

Les drapeaux rouges. Chacun modifie la cote avant même le premier examen complémentaire.

La démonstration

Reprenons l'exemple précédent. Le même test, avec le même RV+ de 3,2 :

| Probabilité avant | Probabilité après un test positif |

|---|---|

| 3 % | 9 % |

| 10 % | 26 % |

| 16 % | 38 % |

| 30 % | 58 % |

| 50 % | 76 % |

La courbe n'est pas linéaire. Le gain d'un test est maximal dans la zone intermédiaire de probabilité, et il est presque nul aux deux extrêmes.

Les deux règles qui en découlent

Première règle. Un test appliqué à une probabilité très basse ne sert à rien, et nuit : il produit une majorité de faux positifs, et chaque faux positif engage un malade dans une chaîne d'examens.

Seconde règle. Un test appliqué à une probabilité très haute ne sert à rien non plus : le diagnostic était déjà porté, et un test négatif ne l'infirmera pas.

Le test n'a de valeur que là où le doute est réel. C'est pourquoi ce Traité place les signes d'appel avant les examens dans chacune de ses Colonnes du diagnostic : ils ne sont pas un préambule clinique, ils sont le calcul de la probabilité initiale.
